YOLOv8 Red & Green Object Detection

This project trains a YOLOv8 model to detect and classify two colored objects, redbox and greenbox, using a custom dataset, then runs real-time detection on a laptop webcam. The model is also exported to ONNX format.
Overview: The model used is YOLOv8n (Nano), trained on two classes, redbox and greenbox, with an image size of 320 by 320, for 10 epochs, using a batch size of 16. The dataset was sourced from Roboflow as a custom red and green box dataset. This assignment was tested and deployed on a local computer using a webcam, no Raspberry Pi was required.

Repository Contents: index.py is the script used to load the trained model and run live detection through the webcam. best.pt contains the trained YOLOv8 model weights in PyTorch format, while best.onnx is the same model exported to ONNX format. args.yaml stores the training configuration used by Ultralytics. results.csv and results.png show training metrics across all epochs. confusion_matrix.png and confusion_matrix_normalized.png show classification performance per class. BoxP_curve.png, BoxR_curve.png, BoxF1_curve.png, and BoxPR_curve.png show precision, recall, F1, and PR curves respectively. labels.jpg shows a sample of labeled training data. train_batch0.jpg, train_batch1.jpg, and train_batch2.jpg show sample training batches with annotations. val_batch0_labels.jpg, val_batch0_pred.jpg, and the equivalent files for batch1 and batch2 show ground truth labels compared against the model's predictions on validation data.
How to Run: First, clone the repository and navigate into this folder using git clone followed by cd into Introduction-to-Robotics/Object_Detection_Assignment. Next, set up a Python virtual environment by running python -m venv yolo, then activate it with .\yolo\Scripts\activate on Windows. Install the required dependencies with pip install --upgrade pip followed by pip install ultralytics opencv-python. Finally, run detection using the trained model and your webcam with python index.py, and press q to quit the detection window.

Training Process: The dataset was downloaded from Roboflow in YOLOv8 format, containing train, valid, and data.yaml. The model was trained using the command yolo detect train model=yolov8n.pt data=data.yaml imgsz=320 epochs=10 batch=16. The best weights were saved to runs/detect/train/weights/best.pt. The model was then exported to ONNX format using yolo export model=best.pt format=onnx imgsz=320 opset=12 dynamic=False simplify=False nms=True.
Results: Training and validation metrics, confusion matrices, and precision and recall curves are included in this folder and can be viewed directly. Sample predictions on validation images show the model's bounding box and label outputs compared against the ground truth images.
Notes: This assignment was completed and tested entirely on a local computer, and Raspberry Pi deployment was not required. The ONNX export is included to demonstrate the conversion step, even though it is not deployed to embedded hardware for this assignment.
